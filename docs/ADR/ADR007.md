ADR-007: Business Terminology is Configuration

Status: Accepted

Decision

All business-facing terminology will be externalized into configuration.

This includes:

Navigation labels
Dashboard card titles
Report names
Severity labels
Risk labels
Product branding
Taglines
Footer text
Welcome messages
Rationale

Business terminology changes more frequently than application logic. Externalizing terminology allows ADOps AI to adapt quickly to stakeholder feedback without requiring code changes or redeployment.
